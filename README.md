# Cognifyz Task 8 – Sass

## Project Overview
This project is created as part of the Cognifyz Technologies Front-End Development Internship. The objective of this task is to use Sass (Syntactically Awesome Style Sheets) to write maintainable and reusable CSS code.

## Features
- Uses Sass variables for consistent styling.
- Uses nested rules to organize CSS selectors.
- Uses reusable styles to reduce code duplication.
- Generates CSS from Sass files.
- Provides a clean and responsive user interface.

## Technologies Used
- HTML5
- CSS3
- Sass (SCSS)
- Visual Studio Code

```text

├── css/

└── README.md
```

## How to Run
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure Node.js and Sass are installed.
4. Compile the Sass file into CSS using:

   ```bash
   sass scss/styles.scss css/styles.css
   ```

5. Open `index.html` in a web browser.

To automatically compile Sass whenever changes are made, run:

```bash
sass --watch scss/styles.scss:css/styles.css
```
